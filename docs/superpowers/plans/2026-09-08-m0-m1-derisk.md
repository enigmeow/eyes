# Uber Voice Control — M0/M1 De-risk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Retire the two blocking unknowns in the design — what Uber's ride-status notifications and trees actually contain during a real ride (M0), and how a button press reaches our code (M1).

**Architecture:** M0 is a host-side Python harness that drives the phone over adb, snapshotting the accessibility tree and Uber's notifications on an interval, writing a replay corpus to disk. No app code. M1 is a minimal Android app whose only job is to prove a volume-key press reaches an `AccessibilityService`; it ships no features.

**Tech Stack:** Python 3.13 + stdlib + pytest (host tooling) · Kotlin + Gradle + Android SDK 36 (device app) · adb 37.0.1

**Spec:** [`docs/superpowers/specs/2026-09-08-uber-voice-control-design.md`](../specs/2026-09-08-uber-voice-control-design.md)

## Global Constraints

- **Target device:** Samsung Galaxy S25 Ultra, `SM-S938U1`, Android 16, **SDK 36**
- **adb device handle:** always the stable mDNS name `adb-R5CXC3JDSYR-YBS99B._adb-tls-connect._tcp`, never `ip:port` (ports randomise across reboots)
- **The phone must not be on a VPN** — it then reports an unreachable tunnel address
- **No cable required.** Wireless debugging only
- **Android app:** `minSdk 33`, `targetSdk 36`, `compileSdk 36`, package `org.stormbirds.eyes`
- **JDK 17** (already installed at `/opt/homebrew/opt/openjdk@17`)
- **Python: stdlib only for runtime code.** pytest is a dev dependency, never imported by `tools/capture/*`
- **M0 captures raw and interprets nothing.** Parsing ride semantics belongs to M5
- **No LLM calls anywhere in this plan**
- **All commands run from the repository root**, which is the working directory you
  start in. Never hardcode an absolute repo path and never `cd` to one: work may run in a
  git worktree, where an absolute path would silently write into the wrong checkout, and
  the `--show-toplevel` substitution is refused outright by worktree sandboxing. Commands
  needing a subdirectory use a relative `cd` (e.g. `cd android`) and say so.

```python
"""Parse `adb shell dumpsys notification` output into structured records.

Pure text in, dicts out. No I/O, no adb. This is the one part of the capture
harness whose correctness cannot be eyeballed during a live ride, so it is
the part that carries real tests.
"""

import re

_RECORD = re.compile(r"NotificationRecord\(.*?pkg=(?P<pkg>[\w.]+).*?key=(?P<key>[^:]+):")
_CHANNEL = re.compile(r"channel=(?P<channel>[\w.\-]+)")
_EXTRA = re.compile(r"android\.(?P<field>title|text)=String \((?P<value>.*?)\)\s*$", re.M)


def parse_notifications(dumpsys_text: str) -> list[dict]:
    """Return one dict per NotificationRecord found in `dumpsys_text`."""
    if not dumpsys_text.strip():
        return []

    out: list[dict] = []
    starts = [m for m in _RECORD.finditer(dumpsys_text)]

    for i, m in enumerate(starts):
        end = starts[i + 1].start() if i + 1 < len(starts) else len(dumpsys_text)
        block = dumpsys_text[m.start():end]

        channel_m = _CHANNEL.search(block)
        extras = {em.group("field"): em.group("value") for em in _EXTRA.finditer(block)}

        out.append({
            "pkg": m.group("pkg"),
            "key": m.group("key").strip(),
            "channel": channel_m.group("channel") if channel_m else None,
            "title": extras.get("title"),
            "text": extras.get("text"),
        })

    return out
```

```python
"""Thin wrapper over the adb CLI.

The single place that knows the device handle. Always uses the stable mDNS
name — wireless-debugging ports randomise across reboots, the mDNS name does not.
"""

import subprocess

DEFAULT_DEVICE = "adb-R5CXC3JDSYR-YBS99B._adb-tls-connect._tcp"


class AdbError(RuntimeError):
    pass


class Adb:
    def __init__(self, device: str = DEFAULT_DEVICE, timeout: int = 30):
        self.device = device
        self.timeout = timeout

    def _run(self, args: list[str]) -> str:
        proc = subprocess.run(
            ["adb", "-s", self.device, *args],
            capture_output=True,
            timeout=self.timeout,
        )
        if proc.returncode != 0:
            raise AdbError(f"adb {' '.join(args)} failed: {proc.stderr.decode(errors='replace')}")
        return proc.stdout.decode(errors="replace")

    def shell(self, cmd: str) -> str:
        return self._run(["shell", cmd])

    def is_connected(self) -> bool:
        try:
            return "device" in self._run(["get-state"])
        except (AdbError, subprocess.TimeoutExpired):
            return False
```

```python
"""Capture one point-in-time snapshot of the device.

Never raises on a failed sub-capture: a single bad dump must not abort a
recording that costs a real Uber fare to reproduce. Failures are recorded
in the snapshot's `errors` list instead.
"""

import datetime
import re
import time

from tools.capture.notifications import parse_notifications

_FOCUS = re.compile(r"mCurrentFocus=(.+)")
_REMOTE_TREE = "/sdcard/eyes_ui.xml"


def take_snapshot(adb, seq: int) -> dict:
    ts = time.time()
    errors: list[str] = []

    tree = ""
    try:
        adb.shell(f"uiautomator dump {_REMOTE_TREE}")
        tree = adb.shell(f"cat {_REMOTE_TREE}")
    except Exception as e:
        errors.append(f"tree: {e}")

    foreground = ""
    try:
        out = adb.shell("dumpsys window | grep -m1 mCurrentFocus")
        m = _FOCUS.search(out)
        foreground = m.group(1).strip() if m else out.strip()
    except Exception as e:
        errors.append(f"foreground: {e}")

    notifications: list[dict] = []
    try:
        notifications = parse_notifications(adb.shell("dumpsys notification --noredact"))
    except Exception as e:
        errors.append(f"notifications: {e}")

    return {
        "seq": seq,
        "ts": ts,
        "iso": datetime.datetime.fromtimestamp(ts, datetime.UTC).isoformat(),
        "foreground": foreground,
        "tree": tree,
        "notifications": notifications,
        "errors": errors,
    }
```

Create `tools/capture/record.py`:

```python
"""Record a corpus of device snapshots over the course of a real Uber ride.

Prints live feedback on every snapshot. This matters: a silent capture failure
during a ride wastes the fare, and the fare is the expensive part.

Usage:
    python -m tools.capture.record --out captures/ride-1 --interval 5
"""

import argparse
import json
import pathlib
import sys
import time

from tools.capture.adb import Adb, DEFAULT_DEVICE
from tools.capture.snapshot import take_snapshot


def main() -> int:
    ap = argparse.ArgumentParser(description="Record device snapshots during a ride.")
    ap.add_argument("--out", required=True, help="output directory")
    ap.add_argument("--interval", type=float, default=5.0, help="seconds between snapshots")
    ap.add_argument("--device", default=DEFAULT_DEVICE)
    ap.add_argument("--watch", default="com.ubercab", help="package to highlight in feedback")
    ap.add_argument("--max-snapshots", type=int, default=0, help="stop after N (0 = unlimited)")
    args = ap.parse_args()

    adb = Adb(device=args.device)
    if not adb.is_connected():
        print(f"ERROR: device not connected: {args.device}", file=sys.stderr)
        print("Check: phone off VPN, wireless debugging on, same Wi-Fi.", file=sys.stderr)
        return 1

    out = pathlib.Path(args.out)
    out.mkdir(parents=True, exist_ok=True)

    started = time.time()
    (out / "manifest.json").write_text(json.dumps({
        "started": started,
        "device": args.device,
        "model": adb.shell("getprop ro.product.model").strip(),
        "sdk": adb.shell("getprop ro.build.version.sdk").strip(),
        "interval": args.interval,
        "watch": args.watch,
    }, indent=2))

    print(f"Recording to {out}  interval={args.interval}s  Ctrl-C to stop")
    seq = 0
    try:
        while True:
            seq += 1
            snap = take_snapshot(adb, seq)
            (out / f"{seq:06d}.json").write_text(json.dumps(snap, indent=2))

            watched = [n for n in snap["notifications"] if n["pkg"] == args.watch]
            nodes = snap["tree"].count("<node")
            fg = snap["foreground"].split("/")[0][-30:]
            flag = "  <-- WATCHED" if watched else ""
            err = f"  ERRORS: {snap['errors']}" if snap["errors"] else ""
            print(f"[{seq:04d}] {time.time()-started:6.0f}s  nodes={nodes:4d}  "
                  f"notifs={len(snap['notifications']):2d}  fg={fg}{flag}{err}")

            for n in watched:
                print(f"         {args.watch}: {n['title']!r} / {n['text']!r}")

            if args.max_snapshots and seq >= args.max_snapshots:
                print(f"\nReached --max-snapshots={args.max_snapshots}. {seq} snapshots in {out}")
                return 0

            time.sleep(args.interval)
    except KeyboardInterrupt:
        print(f"\nStopped. {seq} snapshots in {out}")
        return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

Create `tools/capture/inspect.py`:

```python
"""Summarise a recorded corpus so a human can see what was actually captured.

Answers the two M0 questions from spec section 10:
  - What do Uber's ride-status notifications contain?
  - Does the tree expose vehicle make, colour, and plate?

Usage:
    python -m tools.capture.inspect captures/ride-1
    python -m tools.capture.inspect captures/ride-1 --grep "Camry|plate"
"""

import argparse
import json
import pathlib
import re
import sys


def main() -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("corpus")
    ap.add_argument("--pkg", default="com.ubercab")
    ap.add_argument("--grep", help="regex to search within tree text")
    args = ap.parse_args()

    root = pathlib.Path(args.corpus)
    if not root.is_dir():
        print(f"no such corpus: {root}", file=sys.stderr)
        return 1

    files = sorted(root.glob("[0-9]*.json"))
    if not files:
        print(f"no snapshots in {root}", file=sys.stderr)
        return 1

    print(f"=== {root}  ({len(files)} snapshots) ===\n")

    print("--- notification timeline ---")
    seen: set[tuple] = set()
    for f in files:
        s = json.loads(f.read_text())
        for n in s["notifications"]:
            if n["pkg"] != args.pkg:
                continue
            sig = (n["channel"], n["title"], n["text"])
            if sig in seen:
                continue
            seen.add(sig)
            print(f"  [{s['seq']:04d}] {n['channel']}")
            print(f"         title: {n['title']!r}")
            print(f"         text:  {n['text']!r}")
    if not seen:
        print(f"  (no {args.pkg} notifications captured)")

    if args.grep:
        print(f"\n--- tree matches for /{args.grep}/ ---")
        rx = re.compile(args.grep, re.I)
        hits = 0
        for f in files:
            s = json.loads(f.read_text())
            for m in rx.finditer(s["tree"]):
                lo, hi = max(0, m.start() - 60), m.end() + 60
                print(f"  [{s['seq']:04d}] ...{s['tree'][lo:hi]}...")
                hits += 1
                break
        if not hits:
            print("  (no matches)")

    errs = [json.loads(f.read_text()) for f in files]
    bad = [s for s in errs if s["errors"]]
    print(f"\n--- health ---")
    print(f"  snapshots with errors: {len(bad)}/{len(files)}")
    empty = [s for s in errs if s["tree"].count("<node") == 0]
    print(f"  snapshots with empty tree: {len(empty)}/{len(files)}")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

## Task 8: Determine accessibility-shortcut semantics (no code)

**Files:** none — this is an empirical test that answers a design question.

**Interfaces:**
- Consumes: nothing
- Produces: the answer that decides Task 10's implementation

The open question: does the volume-key accessibility shortcut deliver a *press event*,
or does it merely *toggle a service on and off*? TalkBack is already installed and can
answer this without writing an app.

- [ ] **Step 1: Record the current state**

```bash

adb -s "$D" shell settings get secure accessibility_shortcut_target_service
```

Expected: both `null` or empty.

- [ ] **Step 2: Bind the shortcut to TalkBack**

On the phone: Settings → Accessibility → Accessibility shortcuts →
"Side and Volume up buttons" (or "Volume key shortcut") → select **TalkBack**.

```bash

```

- [ ] **Step 3: Press the shortcut and observe**

Physically press and hold the shortcut keys for 3 seconds. Then:


- [ ] **Step 4: Record the verdict**

- If `enabled_accessibility_services` **now contains TalkBack** (and pressing again

  **Task 10 must use `onKeyEvent()`.**

## Task 10: TriggerService — prove a key press reaches our code

**Files:**

**Interfaces:**
- Consumes: Task 8's verdict, Task 9's build
- Produces: a running `AccessibilityService` that emits `EYES_TRIGGER` to logcat on the
  chosen trigger. M2 builds its voice loop on this signal.

- [ ] **Step 1: Write the service config**

`android/app/src/main/res/xml/accessibility_service_config.xml`:

```xml
<?xml version="1.0" encoding="utf-8"?>
<accessibility-service xmlns:android="http://schemas.android.com/apk/res/android"
    android:accessibilityEventTypes="typeAllMask"
    android:accessibilityFeedbackType="feedbackSpoken"
    android:accessibilityFlags="flagDefault|flagRequestFilterKeyEvents|flagRetrieveInteractiveWindows|flagReportViewIds"
    android:canRequestFilterKeyEvents="true"
    android:canRetrieveWindowContent="true"
    android:canPerformGestures="true"
    android:description="@string/service_description"
    android:notificationTimeout="100" />
```

`flagRetrieveInteractiveWindows` and `canRetrieveWindowContent` are not needed for M1,
but are declared now because M4 requires them and changing service capabilities later
forces the user to re-grant the permission.

- [ ] **Step 2: Write the service**

`android/app/src/main/kotlin/org/stormbirds/eyes/TriggerService.kt`:

```kotlin
package org.stormbirds.eyes

import android.accessibilityservice.AccessibilityService
import android.util.Log
import android.view.KeyEvent
import android.view.accessibility.AccessibilityEvent

/**
 * M1 deliverable: prove that a button press reaches our code.
 *
 * Logs EYES_TRIGGER on a volume-key chord. Ships no other behaviour.
 */
class TriggerService : AccessibilityService() {

    private var volumeDownHeld = false
    private var volumeUpHeld = false

    override fun onServiceConnected() {
        super.onServiceConnected()
        Log.i(TAG, "EYES_SERVICE_CONNECTED")
    }

    /** Fires when the accessibility shortcut activates this service (API 30+). */
    override fun onAccessibilityButtonClicked() {
        Log.i(TAG, "EYES_TRIGGER source=accessibilityButton")
    }

    override fun onKeyEvent(event: KeyEvent): Boolean {
        val down = event.action == KeyEvent.ACTION_DOWN
        when (event.keyCode) {
            KeyEvent.KEYCODE_VOLUME_UP -> volumeUpHeld = down
            KeyEvent.KEYCODE_VOLUME_DOWN -> volumeDownHeld = down
            else -> return false
        }

        Log.d(TAG, "key=${event.keyCode} down=$down up=$volumeUpHeld dn=$volumeDownHeld")

        if (volumeUpHeld && volumeDownHeld) {
            Log.i(TAG, "EYES_TRIGGER source=volumeChord")
            // Return false: do not swallow the keys during M1, so the phone
            // remains usable if the chord is wrong.
        }
        return false
    }

    override fun onAccessibilityEvent(event: AccessibilityEvent?) = Unit

    override fun onInterrupt() = Unit

    companion object {
        private const val TAG = "Eyes"
    }
}
```
